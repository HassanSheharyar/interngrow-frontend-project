# BizSync Pro - InternGrow Frontend Project

A comprehensive and modern Multi-Module Dashboard built with React.js. This project was developed as part of the **InternGrow Frontend Internship Program**. It features a fully responsive, corporate-level user interface with multiple administrative modules, dark/light mode capabilities, and dynamic data handling.

# Live Demo
**View the live project here:** [https://interngrow-frontend-project.vercel.app](https://interngrow-frontend-project.vercel.app/)

---

# Key Features & Modules

# 1. Authentication System
* Complete UI flow for Login, Registration, Forgot Password, OTP Verification, and Reset Password.
* Secure protected routing for authenticated users.

# 2. HR Management Desk (Task 2)
* **Employee Management:** Add, edit, and delete employee records.
* **Kanban Board:** Drag-and-drop functionality for tracking tasks (To Do, In Progress, Done).
* **Export Data:** Ability to export employee data into a CSV file.

# 3. E-Commerce Admin Panel (Task 3)
* **Interactive Dashboard:** Visual statistical cards and dynamic revenue bar charts.
* **Product Catalog:** Advanced data table with Image Upload UI.
* **Smart Filtering:** Search by name, filter by category, and sort by price (High/Low).
* **Pagination:** Smooth pagination for handling large datasets.

# 4. Modern UI / UX Enhancements
* **Global Typography:** Professional 'Segoe UI' font implementation.
* **Theme Switching:** Seamless Dark and Light mode integration.
* **Dynamic Notifications:** Real-time notification badge with "Mark all as read" functionality.
* **Responsive Sidebar & Navbar:** Fully adaptable layout for desktop and mobile screens.

---

# Tech Stack
* **Frontend Library:** React.js
* **Routing:** React Router DOM
* **Styling:** Custom CSS (Flexbox, Grid, CSS Variables for Theming)
* **Notifications:** React Hot Toast
* **Deployment:** Vercel

# How to Run Locally

1.  Clone the repository:
   bash
   git clone [https://github.com/HassanSheharyar/interngrow-frontend-project.git](https://github.com/HassanSheharyar/interngrow-frontend-project.git)

2.  Install Dependencies:
  npm install

3. Start the development server:
   npm run dev
