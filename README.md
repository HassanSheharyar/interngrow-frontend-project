# InternGrow Frontend Development Track - Capstone Project

This repository contains the complete frontend master project developed during the 8-week InternGrow Frontend Track. It is a unified React application featuring multiple dashboards and a complete Capstone CRM System.

## 🚀 Features Implemented
* **Task 1:** Authentication Flow (Login, Register, OTP, Reset Password)
* **Task 2:** HR Dashboard (Employee management)
* **Task 3:** E-Commerce Admin Panel (Products, Orders, Inventory)
* **Task 4:** Project Management System (Kanban Board with Drag & Drop)
* **Task 5:** Real-Time Analytics Dashboard (Mock API, Loading Skeletons, Auto-refresh)
* **Task 6 (Capstone):** CRM System (Full CRUD operations, Sales Funnel, Advanced Filters)

## 🛠️ Technologies Used
* React.js (Vite)
* React Router DOM
* CSS Variables for Dynamic Theming (Dark/Light Mode)
* HTML5 Drag and Drop API

## ⚙️ How to Run Locally
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the local development server.
